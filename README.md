# お金の置き場所ノート

ログインや銀行連携がない、スマートフォン向けの家計整理アプリです。入力した内容は開いたブラウザーの `localStorage` に保存されます。アプリは外部のフォントや分析サービスを読み込みません。

## 起動方法

`index.html` をブラウザーで開けば使えます。ホーム画面への追加とオフライン利用を有効にする場合は、このフォルダーでローカルサーバーを起動してください。

```sh
python3 -m http.server 8000
```

その後、同じ端末のブラウザーで `http://localhost:8000` を開きます。PWAとしてホーム画面へ追加すると、次回以降はオフラインでも利用できます。公開ホスティングに置く場合は HTTPS が必要です。公開先を使う場合、端末からそのサイトへの通信は発生しますが、このアプリ自身は入力データを送信しません。

## 使い方

1. 「口座を追加」から、銀行・証券・現金などを登録します。1口座につき役割はひとつです。
2. STEP 2で役割ごとの合計と目標額、生活防衛資金の目安、目的別貯蓄を確認します。
3. STEP 3で口座ごとの扱い、理由、次の行動、期限を記録します。解約前の6項目はチェックリストです。
4. 「まとめ」で役割別の置き場所と、次の行動を一覧できます。
5. 設定からJSONバックアップを書き出し、別端末で復元できます。復元は端末内の現在の内容を置き換えます。

## 保存と制約

- データはブラウザーごと・端末ごとに分かれます。ブラウザーデータの消去やプライベートブラウズの終了で失われることがあるため、定期的にバックアップしてください。
- JSONバックアップにはschemaVersionが含まれます。現在はバージョン1のみ読み込みます。
- ログインや共有同期、銀行・証券口座との自動連携はありません。家族やフォロワーがそれぞれ自分の端末で使う想定です。
- 元PDFは作業環境に見当たらなかったため、画面と入力項目は依頼文に記載された要件をもとに実装しています。PDFに固有の項目や計算式は反映できていません。
