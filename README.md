# 私のお金の置き場所管理シート

Excelブック「お金置き場所管理シート🏠.xlsx」の3シートをもとに再構築した、ログイン不要のモバイル向け静的Webアプリです。要件とExcel式との照合記録は [REQUIREMENTS-DIFFERENCES.md](REQUIREMENTS-DIFFERENCES.md) を参照してください。

## 起動

ビルド手順や外部ライブラリは不要です。ローカルで動作確認する場合、このフォルダーで次を実行します。

```sh
python3 -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開きます。HTMLファイルを直接開いても基本画面を使えますが、PWAのオフライン利用にはlocalhostまたはHTTPSが必要です。

## 画面と流れ

1. **STEP 1**：最大30件の口座・資産（名義、種類、残高、役割、連携先、メモ）を登録します。役割の「よく分からない」は未分類として扱われ、4役割の集計には含めません。
2. **STEP 2**：役割別の現在額、目標、置き場所、不足額を確認します。目的別の貯めるお金はブックと同じ4行、時期選択肢で管理します。現金で残す金額はExcel式の構造で計算します。
3. **STEP 3**：各口座の判断・理由・次の行動・期限を記録し、残す／保留／解約を検討の件数を確認します。共通の解約前チェック6項目と資金フロー5項目も記録します。

## 保存とバックアップ

- 入力はブラウザーの `localStorage` に自動保存されます。サーバー送信、ログイン、銀行連携、共有同期はありません。
- ブラウザーデータの消去、端末・ブラウザーの変更、プライベートブラウズの終了で消える場合があります。設定からJSONバックアップを書き出し、復元してください。
- JSONには `schemaVersion: 2` が含まれます。復元では版、件数、値を確認し、現在のデータを置き換える前に確認を表示します。既存アプリの同じ端末内データ（schemaVersion 1）は初回起動時に移行します。
- 公開サイトの閲覧にともなう通常のアクセス情報は、Webホスティング事業者から見える場合があります。家計の入力内容はアプリから送信しません。

## 計算の確認

Node.jsがあれば、外部パッケージなしで計算例を確認できます。

```sh
node tests/domain.test.js
```

Excelの数式と入力選択肢の不一致2箇所は [REQUIREMENTS-DIFFERENCES.md](REQUIREMENTS-DIFFERENCES.md) に記録し、選択肢に合わせる補正をしています。
